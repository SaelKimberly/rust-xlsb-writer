# Excel 2023 theme support

- Status: Implemented — reviewed
- Date: 2026-11-19
- Scope: `Workbook::use_excel_2023_theme`, the theme package part,
  workbook relationship and content type, `BrtWbProp`, and the Excel 2023
  default format.
- Gap source: `docs/gap-analysis-rust-xlsxwriter.md` §3.1 and §5.
- Reference: vendored `rust_xlsxwriter` v0.102.0 `workbook.rs`
  (`use_excel_2023_theme`) and `theme.rs` (`THEME_XML_2023`).
- Spec: MS-XLSB §2.1.7.52, §2.4.868, §2.5.22.
- Baseline: `faaa77d feat: add date conditional formats`.

## Goal

Add the reference workbook entry point for the Excel 2023 Office theme:

```rust
let mut workbook = Workbook::new();
workbook.use_excel_2023_theme()?;
let worksheet = workbook.add_worksheet();
worksheet.write(0, 0, "Hello")?;
workbook.save("workbook.xlsb")?;
```

The call must:

- reject workbooks that already contain a worksheet, matching
  `set_default_format`;
- set the default format to Aptos Narrow 11 with the body font scheme;
- set the default row height to 20 pixels and column width to 64 pixels;
- emit `xl/theme/theme1.xml` with the Excel 2023 Office color and font
  schemes;
- emit `BrtWbProp` with `dwThemeVersion = 202300`;
- add the theme content type and workbook relationship.

Out of scope: `use_custom_theme`, `.thmx`/`.xlsx` theme extraction, theme
import from XLSB, and any change to the default output when the method is not
called.

## Aegis Visibility

This is a public workbook API plus a package contract. The theme part is
optional, so default output must remain byte-shape compatible for callers that
never select a theme. The `dwThemeVersion` value is also a durable wire
contract: without it Excel may fall back to the older theme version even
though the part is present.

## Architecture

`rust-xlsb-core`:

- Add `prelude/record/brt_wb_prop.rs` with `BrtWbProp`:
  - `flags: u32`,
  - `dwThemeVersion: u32`,
  - `strName: CodeName`.
- `Default` uses zero flags, zero version, and an empty code name.
- Re-export it from `prelude/record/mod.rs` and `prelude/mod.rs`, and register
  the record in the shared `test_biff_export` table at size 12.

`rust-xlsb-writer`:

- Add `src/theme.rs`:
  - `Theme` copyable enum with `Excel2023`;
  - `THEME_XML_2023` from a checked-in `theme_2023.xml` asset;
  - `version()` returns `202_300`.
- Add `WorkbookSettings.theme: Option<Theme>`.
- `Workbook::use_excel_2023_theme` sets the default format, row height, column
  width, and theme. It must use `set_default_format` so the “before worksheets”
  rule and dimension validation stay in one place.
- `package::build_package` receives the theme through `WorkbookSettings`.
- Add the theme part only when selected.

`package.rs`:

- `content_types(..., has_theme)` adds
  `<Override PartName="/xl/theme/theme1.xml" ContentType="application/vnd.openxmlformats-officedocument.theme+xml"/>`.
- `workbook_rels(sheet_count, has_strings, has_theme)` adds the theme
  relationship after the optional shared-strings relationship.
- `workbook_part` pushes `BrtWbProp` after `BrtBeginBook` when a theme is
  selected.
- `build_package` pushes the theme XML part.

## Wire Contract

| Piece | Value |
|---|---|
| Theme part | `xl/theme/theme1.xml` |
| Theme content type | `application/vnd.openxmlformats-officedocument.theme+xml` |
| Theme relationship | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/theme` |
| Relationship target | `theme/theme1.xml` |
| `BrtWbProp.flags` | `0` |
| `BrtWbProp.dwThemeVersion` | `202300` |
| `BrtWbProp.strName` | empty `CodeName` |

## Compatibility Boundary

- `Workbook::new()` and every workbook that does not call
  `use_excel_2023_theme` keep the current parts and relationship ids.
- Shared strings remain `rId{sheet_count + 2}`; the theme uses the next free
  id.
- `set_default_format` remains the only owner of default-format timing and
  dimension validation.

## Change Necessity

The API is absent and a theme cannot be expressed through existing format
colors: `Color::Theme` only stores an index and needs a theme part and theme
version to resolve. The minimum new owner is one optional theme setting, one
static XML asset, one core record, and package wiring.

  record tests.

## Risks

- Excel may require additional theme metadata beyond `dwThemeVersion`; the
  generated workbook was checked in LibreOffice and with calamine. If Excel
  silently ignores the theme, the fallback is to add `BrtWbProp14` or a
  richer theme relationship after a fixture comparison.
- The theme XML is a static compatibility asset. It is stored as one
  normalized line and should not be reflowed without a byte comparison.
- Excel 2023 Aptos fonts may be unavailable on older systems; Excel falls back
  to a local font while preserving the theme.

## Review

`ThemeReview` found no blocking defects. Two P3 coverage gaps were fixed:

1. The positive theme test now pins the theme relationship to `rId4` when the
   shared-strings relationship is present.
2. The default-package test now asserts that neither the content types nor the
   workbook relationships mention a theme.

The reviewer independently validated the `BrtWbProp` layout and record order,
the decimal `202300` theme version, the theme content type and relationship,
the next-free-id allocation, the Aptos Narrow style-zero wiring, the 300-twip
row height, and `dxGCol = 2158`. It also confirmed that a failed
`use_excel_2023_theme` call after adding a worksheet leaves no partial theme
state.
